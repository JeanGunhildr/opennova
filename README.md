## 🎯 Tentang Proyek

### Latar Belakang

Di tengah persaingan bisnis yang semakin ketat, perusahaan dituntut untuk terus berinovasi dan menyelesaikan permasalahan secara cepat dan efektif. Namun, proses inovasi masih banyak bergantung pada tim internal atau pihak eksternal seperti konsultan, sehingga akses terhadap ide, talenta, dan solusi dari luar perusahaan belum optimal.

Di sisi lain, Indonesia memiliki banyak talenta potensial, mulai dari mahasiswa, peneliti, akademisi, komunitas, hingga startup yang memiliki kemampuan dan ide inovatif. Namun, mereka belum memiliki cukup akses untuk mengaplikasikan kemampuan tersebut pada permasalahan nyata industri. Akibatnya, terdapat kesenjangan antara perusahaan yang membutuhkan solusi dan talenta yang memiliki potensi untuk menciptakannya.

Kondisi ini juga menjadi tantangan bagi talenta muda dalam memasuki dunia kerja. Selain pendidikan, pengalaman dan kontribusi nyata menjadi nilai tambah yang dapat menunjukkan kemampuan seseorang. Kesempatan untuk mengerjakan permasalahan nyata perusahaan dapat menjadi pengalaman sekaligus portfolio yang memperkuat CV dan daya saing di dunia profesional.

Data Global Innovation Index 2025 menunjukkan Indonesia berada di peringkat 55 dari 139 negara, namun masih berada di peringkat 92 untuk Human Capital & Research dan 117 untuk kolaborasi riset antara institusi publik dan industri. Hal ini menunjukkan bahwa potensi inovasi Indonesia masih perlu didukung oleh ekosistem yang mampu menghubungkan talenta, riset, teknologi, dan kebutuhan industri. Upaya tersebut sejalan dengan SDG 9: Industry, Innovation and Infrastructure, khususnya dalam mendorong riset, kapabilitas teknologi, dan inovasi.

### Solusi yang Ditawarkan

Opennova hadir untuk menjembatani kebutuhan inovasi perusahaan dengan potensi talenta Indonesia sekaligus mendukung pencapaian SDG 9 melalui ekosistem Open Innovation & Crowdsourcing. Opennova mempertemukan Seeker (perusahaan/organisasi yang memiliki tantangan) dengan Solver (individu atau tim yang menawarkan solusi).

Melalui Opennova, Seeker dapat mempublikasikan permasalahan atau kebutuhan inovasinya sebagai Challenge, kemudian Solver dari berbagai latar belakang dapat mengembangkan dan mengajukan solusi. Solusi tersebut selanjutnya dapat dievaluasi oleh Seeker untuk menentukan pemenang atau membuka peluang kolaborasi lebih lanjut. Dengan demikian, perusahaan memperoleh akses terhadap perspektif dan solusi yang lebih beragam, sementara Solver mendapatkan kesempatan untuk menerapkan kemampuan pada permasalahan nyata, memperoleh reward dan sertifikat, serta membangun portfolio dari kontribusi nyata.

Melalui model tersebut, Opennova tidak hanya menjadi wadah pencarian solusi, tetapi membangun ekosistem kolaborasi antara industri dan talenta Indonesia. Hal ini secara langsung mendukung SDG 9 dengan mendorong keterhubungan antara kebutuhan industri, riset, teknologi, dan inovasi sehingga potensi inovasi dapat lebih mudah diterapkan menjadi solusi nyata.

### Tujuan Proyek

- 🎯 **Tujuan Utama**: Menciptakan ekosistem inovasi terbuka yang menghubungkan permasalahan nyata industri dengan talenta dan ide inovatif dari seluruh Indonesia secara efisien, kolaboratif, dan terukur.
- 📊 **Target Pengguna**: Seeker (Perusahaan Swasta, BUMN, Instansi Pemerintah, dan UMKM yang membutuhkan solusi inovasi), serta Solver (mahasiswa, peneliti, akademisi, komunitas maker, startup, maupun individu/tim inovator di Indonesia).
- 💡 **Value Proposition**: “Masalah nyata bertemu solusi terbaik”. Opennova tidak hanya menjadi tempat mencari ide, tetapi membangun jembatan langsung antara kebutuhan industri dan talenta inovatif Indonesia, sehingga perusahaan dapat menemukan perspektif dan solusi dari sumber yang lebih luas, sementara Solver memperoleh insentif, pengakuan, dan peluang kolaborasi nyata.

## ✨ Fitur Unggulan (Role Solver)

### Fitur Utama

| Fitur | Deskripsi | Keunggulan |
|----------|--------------|---------------|
| **Jelajah** | Menampilkan berbagai Challenge aktif dari beragam kategori yang dapat ditemukan dan diikuti Solver sesuai minat dan keahliannya. | Membuka akses langsung terhadap permasalahan nyata industri dan peluang inovasi dari berbagai perusahaan. |
| **Ruang Kerja** | Memusatkan Challenge yang sedang maupun telah diikuti beserta progress dan ringkasan informasinya. | Membantu Solver mengelola perjalanan inovasinya secara terstruktur dalam satu ruang kerja. |
| **Detail Challenge** | Menyediakan informasi lengkap mengenai challenge serta akses untuk bergabung/mengikuti challenge, berdiskusi langsung dengan seeker/pembuat challenge melalui fitur ruang diskusi, membatalkan keikutsertaan challenge, mengirimkan solusi, serta mendapatkan feedback penilaian inovasi dari seeker. | Menghadirkan alur end-to-end dari memahami permasalahan hingga mengajukan solusi kepada perusahaan. |
| **Tim Anda** | Menyediakan wadah bagi Solver untuk membuat dan bergabung dalam tim ketika ingin mengerjakan Challenge secara berkelompok. | Memfasilitasi kolaborasi lintas keahlian untuk menghasilkan solusi yang lebih inovatif dan komprehensif. |
| **Perolehan** | Mengelola reward Solver, termasuk melihat hadiah, mengakses sertifikat, dan menarik saldo ke rekening bank. | Mengubah kontribusi inovasi menjadi reward dan pencapaian yang terukur, sekaligus memperkuat portfolio Solver. |

### Fitur Tambahan

- **Landing Page** - Halaman awal yang memperkenalkan Opennova, menjelaskan konsep dan keunggulan platform, serta mengarahkan pengguna untuk mendaftar atau masuk sebagai Solver.
- **Popup Daftar & Popup Masuk** - Memudahkan pengguna melakukan registrasi dan login secara cepat tanpa harus berpindah halaman.
- **Informasi Profil** - Menampilkan dan mengelola informasi pengguna yang relevan sebagai identitas serta mendukung kebutuhan partisipasi dalam platform.
- **Notifikasi** - Memberikan informasi terbaru mengenai aktivitas, submission, reward, dan pembaruan penting lainnya agar pengguna tidak melewatkan informasi.

## ✨ Fitur Unggulan (Role Seeker)

### Fitur Utama

| Fitur | Deskripsi | Keunggulan |
|----------|--------------|---------------|
| **Dashboard** | Menampilkan ringkasan seluruh aktivitas Seeker, seperti jumlah Challenge, Challenge aktif, total dana hadiah, detail Challenge, dan agenda terdekat. | Membantu Seeker memantau kondisi dan perkembangan Challenge dengan cepat dalam satu halaman. |
| **Challenge Anda** | Menampilkan seluruh Challenge yang dibuat Seeker, serta menyediakan akses untuk membuat Challenge baru, melihat progress, dan mengelola Challenge. | Memudahkan perusahaan mengatur seluruh Challenge secara terpusat dan terstruktur. |
| **Buat Challenge Baru** | Menyediakan form untuk mengisi informasi Challenge yang akan dibuat, dan melakukan pembayaran hadiah melalui Virtual Account sebelum Challenge dipublikasikan. | Membuat proses pembuatan Challenge menjadi lebih mudah dan terintegrasi, dari menentukan kebutuhan hingga siap dibuka untuk Solver. |
| **Kelola Challenge** | Digunakan untuk mengelola Challenge yang telah dipublikasikan, mulai dari melihat dan menilai submission Solver, menjalankan tahap Penjurian Ahli, Pitching Final, dan Pengumuman Pemenang, menjawab pertanyaan di Ruang Diskusi, hingga memperbarui atau membatalkan Challenge. | Memastikan proses seleksi solusi berjalan terstruktur, sehingga Seeker dapat menemukan dan memilih solusi terbaik dari berbagai submission. |
| **Legal & Dokumen** | Mengatur pilihan hak cipta inovasi antara Seeker dan Solver serta mengelola data dan berkas resmi untuk penerbitan sertifikat bagi Solver pemenang. | Memberikan kejelasan hak atas inovasi dan kelengkapan dokumen, sehingga proses kolaborasi lebih aman sesuai ketentuan hukum di Indonesia, serta tetap terdokumentasi dengan jelas. |

### Fitur Tambahan

- **Landing Page** - Halaman awal yang memperkenalkan Opennova, menjelaskan konsep dan keunggulan platform, serta mengarahkan pengguna untuk mendaftar atau masuk sebagai Seeker.
- **Popup Daftar & Popup Masuk** - Memudahkan pengguna melakukan registrasi dan login secara cepat tanpa harus berpindah halaman.
- **Popup Informasi Penilaian** - Menyediakan informasi lengkap mengenai teknis, aturan, dan alur penilaian submission Solver yang perlu dipahami oleh Seeker.
- **Popup Informasi Pembayaran** - Menyediakan informasi mengenai minimal hadiah Challenge, biaya publikasi, alur pembayaran, serta ketentuan pengembalian dana apabila Challenge dibatalkan atau tidak disetujui oleh Admin.
- **Popup Transfer Hadiah Via Virtual Account** - Menampilkan nomor Virtual Account yang digunakan Seeker untuk melakukan pembayaran hadiah saat membuat Challenge baru.
- **Popup Pembatalan Challenge** - Menampilkan formulir konfirmasi pembatalan Challenge yang mencakup alasan pembatalan, nomor rekening untuk pengembalian dana, serta input judul Challenge sebagai verifikasi sebelum pembatalan dilakukan.
- **Notifikasi** - Menampilkan berbagai pemberitahuan terkait aktivitas dan perkembangan Challenge, seperti submission baru, hasil penilaian, status Challenge, pembayaran, dan informasi penting lainnya.
- **Informasi Profil** - Menampilkan informasi profil Seeker serta menyediakan akses untuk melihat dan mengelola data akun dan informasi perusahaan.

## 🛠️ Teknologi

### Tech Stack

#### Frontend
```
Framework    	: Next.js 16.3.1 (React 19.2.8, Turbopack, App Router)
UI Library   	: Tailwind CSS v4 (@tailwindcss/postcss), Lucide React (^1.37.0), React Icons (^5.7.0)
State Mgmt   	: React Context (AuthModalContext, LandingModeContext) & React Native Hooks (useState, useEffect, useCallback, useRef)
Validation   	: In-app Client-side Form Validation & Server Action Type Validation
```

#### Backend
```
Runtime      	: Node.js
Framework    	: Next.js Server Actions ("use server") & Server Components
Database     	: PostgreSQL (Supabase Managed Database)
ORM / Driver 	: Supabase Client (@supabase/supabase-js v2.115.0) & @supabase/ssr v0.12.5
Auth         	: Supabase Auth (Cookie-based Session SSR via createBrowserClient & createServerClient)
```

#### DevOps & Tools
```
Deployment   	: Vercel Ready (Next.js Standalone / App Router)
Package Mgr  	: pnpm (v9.0.2 via pnpm-lock.yaml) / npm fallback (package-lock.json)
Testing      	: Belum diimplementasikan
Linting      	: ESLint v9 (eslint-config-next 16.3.1)
TypeScript   	: TypeScript v5
```

### Alasan Pemilihan Teknologi

| Teknologi | Alasan Pemilihan |
|-----------|------------------|
| **Next.js 16 (App Router + React 19)** | Menyediakan kapabilitas *Server Components* (RSC) dan *Server Actions* untuk performa maksimal, zero-bundle backend fetching, SEO yang kuat pada landing page, dan kompilasi instan dengan Turbopack. |
| **Supabase (@supabase/ssr & PostgreSQL)** | Menyediakan platform BaaS (Backend-as-a-Service) tangguh berbasis PostgreSQL relational database dengan bawaan Authentication, Row-Level Security (RLS), dan integrasi cookie-session yang aman untuk Server Components. |
| **Tailwind CSS v4 & `@theme inline`** | Engine Tailwind versi terbaru yang jauh lebih cepat, tanpa perlu `tailwind.config.js` konvensional. Konfigurasi token warna dan keyframe animasi terpusat langsung di `app/globals.css`. |
| **Lucide React & React Icons** | Set ikon modern, ringan, berbasis SVG tree-shakeable yang konsisten untuk seluruh panel antarmuka Seeker, Solver, dan Admin. |
| **HTML5 Canvas (Particle Physics)** | Animasi interaktif mouse-follow partikel pada Hero section landing page dibangun secara native di atas Canvas 2D API tanpa ketergantungan library berat seperti Three.js, menjaga performa tetap 60fps. |

## ⚙️ Instalasi & Setup

### Prerequisites

Pastikan Anda telah menginstall:
- **Node.js**: Versi `20.x` atau lebih baru (disarankan LTS `v20.x` / `v22.x`).
- **Package Manager**: `pnpm` (direkomendasikan v9.0.2) atau `npm` (v10+).
- **Database**: Instance Supabase aktif (Cloud atau Local via Supabase CLI).
- **Git**: Untuk version control dan pengelolaan repository.

### Langkah Instalasi

#### 1️⃣ Clone Repository

```bash
git clone https://github.com/JeanGunhildr/opennova.git
cd opennova
```

#### 2️⃣ Install Dependencies

```bash
# Menggunakan pnpm
pnpm install

# Atau menggunakan npm
npm install
```

#### 3️⃣ Setup Environment Variables

Buat file `.env.local` di root direktori proyek:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHED_KEY=your-supabase-anon-key
```

#### 4️⃣ Setup Database

Jalankan query DDL pada dashboard Supabase SQL Editor untuk tabel relasional (`profiles`, `challenges`, `teams`, `submissions`, dll.) dan terapkan skrip RLS yang ada di:
```bash
supabase/schema_discussions.sql
```

#### 5️⃣ Run Development Server

Jalankan development server menggunakan `pnpm`:

```bash
pnpm dev
```

Aplikasi akan berjalan di:

`http://localhost:3000/`

## 📚 API Documentation

Platform OpenNova mengadopsi arsitektur **Next.js Server Actions** (`"use server"`) sebagai antarmuka API backend terpusat di `lib/actions/`. Semua mutasi data diverifikasi menggunakan session cookie Supabase secara aman.

### 1. Challenge & Submission Management (`lib/actions/challenge.ts`)

#### `createChallengeAction`
- **Fungsi:** Membuat draft tantangan baru dari wizard Seeker beserta objektif, kriteria, dan pembayarannya.
- **Input Payload:**
  ```typescript
  {
    name: string;
    description: string;
    categoryId: string;
    objectives: string[];
    requirements: string[];
    timelines: { title: string; startDate: string; endDate: string }[];
    criteria: { name: string; description: string; stage: "expert" | "pitch" }[];
    prizePool: number;
    creationFee: number;
    totalPayment: number;
    deadline: string;
    copyrightPath: string;
    thumbnailPath?: string;
  }
  ```
- **Response:**
  ```typescript
  { success: true, challengeId: "uuid-challenge" } | { success: false, error: string }
  ```

#### `registerForChallengeAction`
- **Fungsi:** Mendaftarkan solver (baik sebagai individu ataupun tim) ke challenge terbuka.
- **Input Payload:**
  ```typescript
  {
    challengeId: string;
    participationType: "individual" | "team";
    teamId?: string;
  }
  ```
- **Response:**
  ```typescript
  { success: true, entryId: "uuid-entry" } | { success: false, error: string }
  ```

#### `submitSolutionAction`
- **Fungsi:** Mengunggah link dokumen Google Drive solusi peserta sebelum deadline.
- **Input Payload:**
  ```typescript
  {
    entryId: string;
    driveUrl: string;
  }
  ```
- **Response:**
  ```typescript
  { success: true, submissionId: "uuid-sub" } | { success: false, error: string }
  ```

---

### 2. Team Management (`lib/actions/team.ts`)

#### `createTeamAction`
- **Fungsi:** Membentuk tim baru dengan pengguna aktif sebagai kapten dan menghasilkan 6 digit kode undangan unik.
- **Input Payload:**
  ```typescript
  { name: string }
  ```
- **Response:**
  ```typescript
  { success: true, teamId: "uuid-team", joinCode: "NOV789" } | { success: false, error: string }
  ```

#### `joinTeamAction`
- **Fungsi:** Mengizinkan solver lain bergabung ke dalam tim yang aktif menggunakan kode undangan.
- **Input Payload:**
  ```typescript
  { joinCode: string }
  ```
- **Response:**
  ```typescript
  { success: true, teamName: "Tim Inovasi Maju" } | { success: false, error: string }
  ```

---

### 3. Seeker Evaluation & Stage Progression (`lib/actions/seeker-manage.ts`)

#### `advanceChallengeStageAction`
- **Fungsi:** Mengubah status siklus hidup tantangan (misal: memajukan dari tahap `open` ke `expert_judging` atau `final_pitch`).
- **Input Payload:**
  ```typescript
  {
    challengeId: string;
    targetStage: "PENJURIAN_AHLI" | "PITCHING_FINAL" | "PENGUMUMAN_PEMENANG";
  }
  ```
- **Response:**
  ```typescript
  { success: true, newStatus: "expert_judging" } | { success: false, error: string }
  ```

#### `saveEvaluationScoresAction`
- **Fungsi:** Menyimpan matriks skor penilaian kriteria juri terhadap satu submisi peserta.
- **Input Payload:**
  ```typescript
  {
    entryId: string;
    scores: Record<string, number>; // { [criterionId]: 85 }
  }
  ```
- **Response:**
  ```typescript
  { success: true } | { success: false, error: string }
  ```
